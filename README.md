# Pomodoroom

Pomodoroom é uma aplicação web baseada na técnica Pomodoro para gerenciamento de foco, tempo e tarefas.

O projeto foi desenvolvido utilizando HTML, CSS e JavaScript puro com foco em prática de lógica de programação, gerenciamento de estado, manipulação do DOM e arquitetura front-end sem frameworks.

## Demonstração

- Projeto online: https://kaickismael.github.io/pomodoroom/
- Repositório: https://github.com/kaickismael/pomodoroom

## Funcionalidades

- Temporizador Pomodoro
- Sessões de foco, pausa curta e pausa longa
- Alternância automática entre sessões
- Barra de progresso dinâmica
- Sistema de gerenciamento de tarefas
- Controle de pomodoros por tarefa
- Edição de tarefas
- Configurações personalizadas de tempo
- Auto start de sessões
- Interface responsiva
- Alteração dinâmica de tema conforme sessão ativa

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript

## Conceitos praticados

Durante o desenvolvimento deste projeto, foram trabalhados conceitos como:

- Manipulação do DOM
- Gerenciamento de estado
- Estruturação modular de código
- Separação de responsabilidades
- Eventos e interação com usuário
- Controle de timers
- Renderização dinâmica da interface
- Templates dinâmicos
- Arquitetura front-end sem frameworks

## Estrutura do projeto

O projeto foi separado em módulos para melhorar organização e manutenção:

- Engine → lógica principal da aplicação
- Controller → controle do fluxo da aplicação
- Dashboard/View → renderização da interface
- Tasks → gerenciamento de tarefas
- Menu → gerenciamento de configurações
- Actions → inicialização de eventos
- Effects → efeitos visuais e animações

## Como executar o projeto

Clone o repositório:

```bash
git clone https://github.com/kaickismael/pomodoroom.git
```

Entre na pasta:

```bash
cd pomodoroom
```

Abra o arquivo `index.html` no navegador.

## Objetivo do projeto

O principal objetivo deste projeto foi aprofundar conhecimentos em JavaScript puro e entender melhor conceitos fundamentais do desenvolvimento front-end sem depender de frameworks.
